# OmniSync

OmniSync is an AI-powered home intelligence platform that optimizes food usage,
energy consumption, and daily commutes using predictive analytics.

## Features
- Fridge Ninja – Prevent food waste
- Energy Exorcist – Reduce power bills
- Commute Whisperer – Smarter travel decisions

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI
- Deployment: Vercel + Render

## Run Locally
Backend:
uvicorn main:app --reload

Frontend:
Open index.html in browser
